Our Docker OpenTelemetry integration helps you stream metrics and logs from Docker containers through the OpenTelemetry Collector Contrib distribution. Once the collector forwards data via OTLP, you can explore it in New Relic dashboards, charts, and alerts.

This guide uses the OpenTelemetry Collector Contrib distribution to collect Docker container metrics through the Docker Stats Receiver, which collects container resource usage metrics (CPU, memory, network, disk I/O). You need a [New Relic account](https://newrelic.com/signup) and a license key to complete the setup.
