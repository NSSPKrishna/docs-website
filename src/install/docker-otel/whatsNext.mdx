## Docker container metrics

The OpenTelemetry Collector's Docker Stats receiver collects resource usage metrics from Docker containers. Below are the key metrics available:

<CollapserGroup>
  <Collapser
    id="cpu-metrics"
    title="CPU metrics"
  >
    <table>
      <thead>
        <tr>
          <th style={{ width: "350px" }}>
            Metric
          </th>
          <th>
            Description
          </th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <td>
            `container.cpu.usage.total`
          </td>
          <td>
            Total CPU time consumed by the container in nanoseconds
          </td>
        </tr>
        <tr>
          <td>
            `container.cpu.usage.kernelmode`
          </td>
          <td>
            CPU time consumed by the container in kernel mode in nanoseconds
          </td>
        </tr>
        <tr>
          <td>
            `container.cpu.usage.usermode`
          </td>
          <td>
            CPU time consumed by the container in user mode in nanoseconds
          </td>
        </tr>
        <tr>
          <td>
            `container.cpu.usage.system`
          </td>
          <td>
            System CPU usage in nanoseconds
          </td>
        </tr>
        <tr>
          <td>
            `container.cpu.usage.percpu`
          </td>
          <td>
            Per-CPU usage in nanoseconds
          </td>
        </tr>
        <tr>
          <td>
            `container.cpu.throttling_data.periods`
          </td>
          <td>
            Number of periods with throttling active
          </td>
        </tr>
        <tr>
          <td>
            `container.cpu.throttling_data.throttled_periods`
          </td>
          <td>
            Number of periods when the container was throttled
          </td>
        </tr>
        <tr>
          <td>
            `container.cpu.throttling_data.throttled_time`
          </td>
          <td>
            Total time that the container was throttled in nanoseconds
          </td>
        </tr>
        <tr>
          <td>
            `container.cpu.percent`
          </td>
          <td>
            Percentage of host CPU used by the container
          </td>
        </tr>
      </tbody>
    </table>
  </Collapser>
